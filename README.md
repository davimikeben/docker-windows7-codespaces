# 📁 Pasta compartilhada

Arquivos colocados **nesta pasta (`shared/`)** aparecem dentro do Windows 7 em:

- 🖥️ Área de trabalho → pasta **`Shared`**
- 💽 Drive **`Z:`**

Use para trocar arquivos entre o host (ou Codespace) e a VM sem precisar de rede.

> Coloque instaladores, documentos ou scripts aqui e acesse pelo drive `Z:` dentro do Windows.
